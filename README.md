## Lancer en local

Aucune installation nécessaire — ouvrir directement `index.html` dans un navigateur, ou servir le dossier :

```bash
git clone https://github.com/Ranto-nyaina/portofolio.git
cd portofolio
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.
